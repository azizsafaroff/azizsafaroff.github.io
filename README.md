# azizsafaroff.github.io

Developer website for apps published under AdMob account
`pub-2851742791384452`.

- `app-ads.txt` — IAB authorised-sellers file. Must stay at the domain root
  and be served as plain text; AdMob crawls it to verify that bids claiming
  to come from these apps are genuine. It is account-wide, so one line covers
  every app on the account.
- `index.html` — landing page, so the *Developer website* link on the Play
  listing is not a 404.

Source of truth: `github_pages/` in the 60LazyApps monorepo.
